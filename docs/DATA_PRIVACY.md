# Privacidade e Dados

Este repositório utiliza somente dados fictícios e sanitizados para fins de portfólio.

A base pública contém apenas dimensões e tabelas fato necessárias para demonstrar a modelagem analítica.

Não devem ser publicados neste repositório dados financeiros reais, credenciais, chaves, tokens, URLs privadas, IDs de formulários ou planilhas privadas, logs operacionais ou respostas brutas contendo informações pessoais.

O arquivo Power BI disponibilizado é a versão preparada para portfólio.
